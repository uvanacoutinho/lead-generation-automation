# Lead Generation Automation Pipeline using Python

## Internship Project – Data Automation & Lead Generation  
Uvana Coutinho | 2nd May 2026

---

## Project Overview
This project implements an automated pipeline that converts raw customer data into a structured CRM-ready lead dataset using Python. It focuses on data cleaning, feature engineering, and generating actionable business leads.

---

## Key Features
- Load and process raw CSV dataset  
- Clean missing values and remove duplicates  
- Generate missing emails using rule-based logic  
- Create Lead ID, Status, and Priority fields  
- Fully automated pipeline execution  
- Export final dataset to Excel  

---

## Tech Stack
Python, Pandas, Jupyter Notebook / Google Colab, Excel

---

## How to Run
Open `lead_generation.ipynb` → run all cells → execute `run_pipeline()` → output saved as `lead_generation_output.xlsx`

---

## Output
Structured CRM-ready dataset containing lead information like name, email, status, priority, and source.
