## Project Overview

This project demonstrates a complete end-to-end Lead Generation Automation Pipeline using Python. The objective is to transform raw data into a structured and usable lead dataset suitable for CRM systems, sales outreach, and business analytics.

The pipeline automates the entire workflow from data loading to final export, making it reusable and scalable.

---

## Key Features

- Data loading from CSV dataset
- Data cleaning (handling missing values and duplicates)
- Email generation for missing values (bonus feature)
- Feature engineering (Lead ID, Status, Priority)
- Structured transformation of raw data into CRM-ready format
- Automated pipeline execution using a single function
- Export of final dataset to Excel format

---

## Tech Stack

- Python
- Pandas
- Google Colab / Jupyter Notebook
- Excel (output format)

---

## How It Works

1. Load dataset (CSV file)
2. Simulate missing email values for testing
3. Transform raw data into structured lead format
4. Generate emails for missing entries using name-based logic
5. Clean and enrich dataset
6. Add Lead ID, Status, and Priority fields
7. Export final dataset to Excel
8. Run entire workflow using `run_pipeline()` function

---

## Output
